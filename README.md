# signal-domain

`signal-domain` is the shared public contract crate for the Signal domain taxonomy extracted from `signal-spirit`.

The canonical source is `schema/domain.schema`. Rust contract types are generated by `schema-rust` into `src/schema/domain.rs` and checked in so consumers can audit the exact public layout. `Domain::All` and `DomainScope::All` are shared contract values here; consumers should use this crate directly instead of re-declaring local domain enums.

The local ScopeOf reference contracts treat root Scope `All` as a whole-tree filter. Scope filtering is provisionally directional, overlap is provisionally symmetric, and Domain `All` provisionally matches any scope. These unruled relation choices remain visibly tagged as assumptions beside their implementations.

## Domain taxonomy

The complete domain tree lives in [`schema/domain.schema`](schema/domain.schema).

This crate intentionally contains no daemon, runtime, storage, or policy behavior. Default features are lean; enable `dotos-text` only when the DOTOS text projection is needed.
